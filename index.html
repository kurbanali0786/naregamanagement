🏠 Quick Summary

👷 Labour Profile / Summary

Search karke ek ya kai Labour select karein (kuch bhi select na karein to Sabhi Labour aa jaayenge) — Naam, Jobcard No., Kul Demand, Kul Din, Kul Payment, Credited/Pending sab dikhega. Date range aur status (Credited/Pending/All) se bhi filter kar sakte hain.

💾 Data Backup / Restore

Apna pura data ek JSON file me safe rakhein — Firebase kharab ho ya galti se data delete ho jaaye, to isi file se wapas load kar sakte hain.

➕ Add Labour

📥 Bulk Labour Import (CSV / Excel / PDF)

Format: Jobcard No, Name, Aadhar No, Status — pehli line header honi chahiye. Sirf Jobcard No. aur Name zaroori hain, baaki khaali chhod sakte hain. Excel (.xlsx/.xls), CSV ya PDF teeno chalenge — koi bhi Font (Hindi/English) ho, sab support hai. Agar file me Sr. No. / Serial No. jaisa koi column bhi hai to koi dikkat nahi — wo apne aap ignore ho jaayega, kyunki number app khud lagata hai.

📋 Mustroll Paste karke Labour Add karein

NREGA site ki Mustroll table select karke Copy (Ctrl+C) karein, neeche Paste (Ctrl+V) karein. Har row ka Naam + Jobcard Number ('/' ke baad wala part) nikal ke seedha Labour list me add hoga — koi Match nahi hoga. Ek jobcard number max 2 baar (pati-patni) aa sakta hai, 3rd baar aane par wo skip ho jayega.

⚡ Ek Paste se Sab Kuch — Demand + Payment + AC Credit

NREGA site ki Mustroll table select karke Copy (Ctrl+C) karein aur neeche Paste (Ctrl+V) kar dein. App khud har row se Naam, Jobcard, Kul Din, Payment (कुल नकद भुगतान), Status aur Credited Date nikaal lega — ek hi click me Demand + Payment ban jayegi, aur jiska Status/Credited Date bhara hoga wo seedha AC Credit bhi ho jayega. Baaki "Pending" rahenge, jinhe baad me 🏦 tab se ek saath Credit kar sakte hain.
